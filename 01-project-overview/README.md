# Project Overview

## iGaming Game Metadata Database & Data Quality Management

This independent portfolio project simulates the handling of game metadata received from multiple iGaming providers. It demonstrates how incoming records can be inspected, validated, investigated, standardised and prepared for review before being added to a central game database.

## Project scope

The exercise uses **100 synthetic game records** representing five providers. It focuses on the data-operations lifecycle rather than on building or operating a live gaming platform.

The workflow covers:

1. Inspecting an incoming game metadata feed.
2. Checking fields against provider and market reference data.
3. Detecting missing, duplicate, invalid and inconsistent values.
4. Recording issues, evidence, proposed actions and resolution status.
5. Preparing a separate cleaned working dataset while preserving the raw feed.
6. Revalidating proposed corrections.
7. Separating records eligible for simulated handover from records requiring further investigation.

## Tools

- Microsoft Excel
- Excel formulas and data-validation checks
- PivotTables

## Main outputs

- Original incoming feed and reference data
- Cleaned working dataset
- Issue log and investigation notes
- Data quality report
- Exception queue
- Game master dataset prepared under the exercise's validation rules

## Important note

This is a simulated training project. Game records, game titles, identifiers, RTP values, market assignments and provider metadata are synthetic. Real provider names are used only to make the examples representative; the data does not represent verified provider catalogues, real feeds or commercial integrations.
