# Project Documentation

This folder contains the written report describing the iGaming game metadata data-quality exercise.

## Documents

- `iGaming_Game_Metadata_Project_Report.pdf` — PDF report covering the project objective, workflow, data-quality findings, investigation outcomes, proposed cleaning actions, validation results, limitations and recommendations.
- `iGaming_Game_Metadata_Project_Report.docx` — editable Word version of the report.

## Suggested reading order

1. Read the executive summary and project workflow.
2. Review the initial data-quality findings.
3. Read the issue investigations and proposed corrections.
4. Compare the initial and post-cleaning validation results.
5. Review the outstanding actions and project limitations.

## Data disclaimer

The report describes a simulated portfolio exercise using synthetic game records and reference rules. It does not describe an actual provider integration, production database or work performed for any named company.
