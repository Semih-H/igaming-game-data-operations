# Project Documentation

This folder contains the documentation for the
iGaming Game Metadata Database & Data Quality project.

## Documents

- iGaming_Game_Metadata_Project_Report.pdf
  - Project overview, methodology, findings,
    investigation history and final results.

- iGaming_Game_Metadata_Project_Report.docx
  - Editable version of the project report.

## Data Disclaimer

All game records, titles, RTP values and market rules
are synthetic training examples.

The project does not represent actual provider feeds,
commercial integrations or verified market approvals.
